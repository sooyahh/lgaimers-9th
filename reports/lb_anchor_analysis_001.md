**전략적 함의:** 같은 로컬 개선폭이라도 **분포 shift에 강건해지는 변화를 우선**하라.
100등까지 LB +224.57이 필요한데, ratio 1.66이면 로컬 **+135**, ratio 1.0이면 로컬 **+225**가 필요하다.

| 대비 | 비교 대상 | 측정 대상 |
|---|---|---|
| **A** | EXP-004 (44, 19–23) vs **NEW** (L42, 19–23) | 동일 학습 창에서의 **feature-set 전이 효과** |

**여전히 얻을 수 없는 것:** ID-drop 효과와 2024-추가 효과의 **상호작용**. 네 번째 칸(44 feat + 2019–2024)이 필요하다. 두 효과가 모두 크게 나온 이상 상호작용도 0이 아닐 수 있으나, 제출 1회를 쓸 만큼 시급하지는 않다.

> 표현 정정: 이것은 **"2×2 완성"이 아니다.** 한 번의 제출로 **두 개의 핵심 대비**를 확보하는 것이다.

**비용:** 학습 1회(L42, train 2019–2023, ~150초) + 제출 1회. 새 `experiment_id`로 등록한다.
서버 추론 소요는 기존 제출 2건 모두 **2초**였으므로 시간 제한은 무관하다.

### 4.1 사전 해석 규칙 (결과를 보기 전에 freeze)

새 제출의 LB 점수를 `S`라 하면, 관측된 ΔLB가 **정확히 두 항으로 가산 분해된다.**

$$\underbrace{877.60 - 406.95}_{470.65} = \underbrace{(S - 406.95)}_{\text{feature 효과 @ 2019–23 고정}} + \underbrace{(877.60 - S)}_{\text{2024 추가 효과 @ L42 고정}}$$

**기준선:** 로컬 2024 holdout에서 ID-drop 효과는 **+161.79**였다.
그것이 2025로 1:1 전이되면 **`S ≈ 569`**이고, 이때 2024 추가 효과는 `≈ +309`가 된다.

| 관측 `S` | 읽는 법 |
|---|---|
| **≈ 406.95** | ID 제거의 2025 효과가 거의 없음 → EXP-005 상승의 대부분이 **2024 추가** |
| **≈ 569** | ID 제거 효과가 로컬과 동일하게 전이 (transfer ratio ≈ 1) → 2024 추가 ≈ +309 |
| **> 700** | ID 제거 효과가 **증폭** — 2025의 unseen ID 비율이 2024(투수 19.86%)보다 높다면 자연스러운 결과 |
| **≈ 877.60** | ID 제거가 2025에서도 핵심 → 2024 추가 효과는 작음 |

이 규칙은 **제출 전에 확정하며, 결과를 본 뒤 수정하지 않는다.**

**실측 결과 (2026-08-19): `S = 676.2128868651`**

`569 < 676.21 < 700` → 표의 두 번째와 세 번째 행 사이. **전이율 1.664로 증폭 방향**이며,
"ID 제거 효과 없음"(≈407)과 "2024 추가 효과 없음"(≈878) 두 극단은 모두 기각됐다.
규칙은 결과를 본 뒤 수정하지 않았다.

## 5. RECENCY-AUDIT-001 설계 (제안, 미실행)

### 5.1 primary CV에 대한 표현 정정

이전 버전에서 "로컬 primary fold는 제출 모델과 구조적으로 다르다"고 기술했다. **과장이므로 정정한다.**

- local primary: `≤2023 → 2024`
- final submit: `≤2024 → 2025`

**구조는 동일하다** (직전 시즌까지 학습 → 다음 시즌 예측). primary CV는 제출의 올바른 대리다.
차이는 **local에서는 가장 최신 regime을 학습에 넣을 수 없다**는 것이고, 그로 인한 절대 수준 차이가 §3에서 −171.23으로 관측됐다.

따라서 primary CV를 폐기할 문제가 아니라, **최근 한 시즌의 정보 가치가 시간에 따라 얼마나 안정적인지를 추가로 감사할 문제**다.

### 5.2 설계 — 3 fold × 3 조건 (9 fit)

한 fold(특히 2023)만 쓰면 regime shift 하나에 결론이 매달린다. 세 valid 시즌에서 paired로 본다.
**데이터 양 증가와 최근성을 분리하기 위해 volume-matched 조건을 넣는다.**

| valid | (A) gap | (B) immediate | (C) volume-matched immediate |
|---|---|---|---|
| 2022 | 2019–2020 (2시즌) | 2019–2021 (3시즌) | 2020–2021 (2시즌) |
| 2023 | 2019–2021 (3시즌) | 2019–2022 (4시즌) | 2020–2022 (3시즌) |
| 2024 | 2019–2022 (4시즌) | 2019–2023 (5시즌) | 2020–2023 (4시즌) |

| 대비 | 명칭 | 정확한 의미 |
|---|---|---|
| **B − A** | `expanding_history_effect` | 직전 시즌 하나를 expanding하게 추가한 총 효과 |
| **C − A** | `window_shift_effect` | **동일 시즌 수**에서 학습 창을 1년 앞으로 이동 (가장 오래된 시즌을 빼고 가장 최근 시즌을 넣음) |
| **B − C** | `old_history_inclusion_effect` | 최신 창에 **가장 오래된 시즌 하나를 추가**한 효과 |

**항등식으로 완전히 분해된다:**

$$\Delta_{\text{expanding}} = \Delta_{\text{window shift}} + \Delta_{\text{old history}}$$

2024 valid 예시:

```
A: 2019–2022 (4시즌)   B: 2019–2023 (5시즌)   C: 2020–2023 (4시즌)

B − A : 2023을 추가한 expanding-history 효과
C − A : 2019를 빼고 2023을 넣은 window shift 효과
B − C : 2020–2023에 2019를 되넣은 old-history 효과
```

> **명칭 주의 (이전 버전 정정):** `C − A`를 **"순수 recency"라 부르지 않는다.**
> 같은 시즌 수라도 2019와 2023은 row 수·선수 구성·regime·feature 분포가 다르므로,
> 측정되는 것은 "창을 한 해 앞으로 옮긴 효과"이지 시간 recency만이 아니다.
> 마찬가지로 `B − C`는 generic한 데이터 양 효과가 아니라 **"오래된 시즌 하나를 추가한 효과"**다.

**진짜 volume 통제는 이번 범위 밖이다.** 그러려면 B의 학습 row를 무작위로 줄여 A와 row count를 맞춰야 한다.
현재 알고 싶은 것은 완전한 causal decomposition이 아니라
**"최신 history를 얼마나 유지하고 오래된 history를 얼마나 버려야 2025 일반화가 좋아지는가"**이므로,
A/B/C 세 모델이면 실용적으로 충분하다.

**통제:** L42, CatBoost 300/0.05/depth6/Logloss, seed 42, **sample weight 균일(1.0)** — weight 효과를 섞지 않기 위해 이 감사에서는 가중치를 끈다. metric·전처리는 기존 그대로.

### 5.3 WEIGHT-LAG-001 (후속, 별도)

**⚠️ 2024 weight를 LB로 직접 튜닝해서는 안 된다.** Public = Private이므로 `2.4 제출 / 4.0 제출 / 6.0 제출` 식의 탐색은 Public LB를 validation set으로 쓰는 것이며 대회 원칙과 충돌한다.

대신 **lag-relative** 스케줄로 로컬에서 고른다. valid year `Y`, 학습 시즌 수 `L`, lag `1..L` (lag 1 = 직전 시즌)에 대해

$$w(\text{lag}) = m^{\,1-\frac{\text{lag}-1}{L-1}} \qquad (w(1)=m,\; w(L)=1)$$

현행 B-1 `{2019:1.0, 2020:1.2, 2021:1.4, 2022:1.6, 2023:2.0}`은 `L=5`에서 이 공식의 **`m = 2.0`과 거의 일치**한다
(`m=2.0` → 2.00 / 1.68 / 1.41 / 1.19 / 1.00).

따라서 `m ∈ {1.0, 1.5, 2.0, 3.0, 4.0}`을 2022/2023/2024 세 fold에서 동일 규칙으로 테스트하고 (15 fit),
paired delta가 안정적으로 좋은 `m`을 고른 뒤 final에 적용한다 — **2025 LB를 보지 않고 결정할 수 있다.**
